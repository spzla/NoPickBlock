# NoPickBlock
A minimal plugin for denying pick-blocking specific blocks with data.

### Usage:
To deny a player or group from pick blocking a specific block, add a permission: `nopickblock.deny.block.chest`.

To deny a player or group from pick blocking a specific block with data, add a permission: `nopickblock.deny.data.chest`.

To allow bypassing any rules, add the permission `nopickblock.bypass`.

Command blocks are denied from data pick blocking by default.
